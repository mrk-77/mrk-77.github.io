# Mreza Dev — Security Research & Engineering

A Jekyll-based security engineering portfolio and technical blog, optimized for GitHub Pages.

## Stack

- Jekyll + Liquid
- GitHub Pages
- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Dark/light theme with system preference support

## Publish

1. Push the repository to `mrk-77/mrk-77.github.io`.
2. In **Settings → Pages**, deploy from the `main` branch and repository root.
3. If you use a custom domain, update `url` in `_config.yml`.
4. Add your real social/email links when ready.

## Content

Create posts in `_posts/` using the Jekyll naming convention:

`YYYY-MM-DD-title.md`

Use categories such as `Research`, `Writeup`, `Security`, `DevSecOps`, or `AI Security`.
